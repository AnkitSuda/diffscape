# Internationalization

**Status: English and Hindi are implemented.** The language preference is stored locally and the document's `lang` attribute updates with the selected language. Date/time display uses the corresponding browser locale. Dynamic paths, refs and Git diff text remain unmodified data.

This is a small in-app dictionary rather than a full i18n framework. Translation completeness, pluralization, long-string layout, VoiceOver pronunciation and a contributor workflow have not been formally reviewed; treat the Hindi interface as an initial translation, not a localization certification.

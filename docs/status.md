# Implementation status

Last checked: 2026-11-01 in the `diffscape-2` implementation worktree (Apple Silicon macOS, Node 24.16.0, pnpm 12.15.0, Vite 8.3.5, React 19.3.1, TypeScript 6.0.3, ESLint 10.14.0, Vitest 5.0.5, Rust 1.94.1, Xcode 27).

This page reports verified repository evidence and known gaps. Diffscape is an early functional desktop implementation, not a signed or release-ready product.

| Area                                               | Status                                        | Evidence / notes                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tauri 2 + Rust + React + TypeScript + Vite         | Implemented                                   | Root manifests, `src-tauri/`, and `src/`; Vite production build and native `.app` build pass                                                                                                                                                                                                                                                                                          |
| pnpm isolated linker + global virtual store        | Configured                                    | `pnpm-workspace.yaml`; `pnpm config get nodeLinker` → `isolated`, `virtualStoreType` → `global`; two linked worktrees installed sequentially from frozen lockfiles; both resolved React/Vite to the same `/Users/apple/Library/pnpm/store/v11/links` package paths                                                                                                                    |
| Worktree discovery                                 | Implemented                                   | NUL-delimited `git worktree list --porcelain -z`; canonical paths include linked worktrees outside the selected checkout; capped at 64 worktrees                                                                                                                                                                                                                                      |
| Change aggregation and identity                    | Implemented                                   | Worktree-file IDs are path-scoped; same relative path remains separate per worktree; aggregate unique-path and worktree-file counts are separate                                                                                                                                                                                                                                      |
| Working / staged / total changes                   | Implemented                                   | Porcelain status and per-worktree merge-base comparisons; total includes committed, staged, unstaged and untracked content; missing bases and detached HEAD are explicit                                                                                                                                                                                                              |
| Comparison-base selection                          | Implemented                                   | Local branches and 7–64 character commit IDs; per-repository choice persists locally; each worktree resolves its own merge-base; actual label/OID and unresolved errors are visible. Rust tests cover `feature`, a commit ID, and an invalid selection with no fallback                                                                                                               |
| Rename, Unicode, binary and large files            | Implemented with limits                       | Rename source path retained; Unicode text handled; binary detection; 2 MB per-file, 1.5 MB diff, 16 MB Git output, 2,000 paths/worktree, 20 s/Git invocation                                                                                                                                                                                                                          |
| Read-only Git behavior                             | Locally verified, not a formal security proof | Fixed argv only, no shell, optional locks disabled, prompts/config globals disabled, hooks path neutralized, external diff/textconv disabled; integration test confirms Git index bytes remain unchanged across scans/diff reads                                                                                                                                                      |
| Watcher and reconciliation                         | Implemented                                   | Debounced bounded event queue, per-worktree observers, 2-second metadata reconciliation, stale observer removal; watcher test confirms user-file events and ignores `.git` metadata. Native interactive lifecycle stress test remains outstanding                                                                                                                                     |
| Three-pane UI, filters, keyboard and accessibility | Implemented                                   | Native titlebar, compact toolbar, expandable hierarchical file tree, duplicate paths with separate worktree leaves, pointer/keyboard pane splitters, path/status filter, keyboard search/navigation, focus styles, split/unified diff                                                                                                                                                 |
| Worktree activity ordering                         | Implemented                                   | Branch-name or newest observed event sort; unobserved worktrees are explicitly labeled and sorted last. This is app observation time, not inferred Git history; activity is not persisted across restarts                                                                                                                                                                             |
| Appearance and compact windows                     | Implemented                                   | System light/dark semantic surfaces; AO Browser fixtures visually checked in both appearances. Native app launched and inspected at 1100×760 with 800×560 minimum; panes and base toolbar remain usable                                                                                                                                                                               |
| Persistence, picker, localization                  | Implemented                                   | Last repository, language, notification preference in local storage; Tauri folder picker; English/Hindi strings and document `lang` update                                                                                                                                                                                                                                            |
| Notifications / reveal                             | Implemented                                   | Notifications are opt-in and request permission on enable; Finder reveal is supported. Configurable editor launch is not implemented                                                                                                                                                                                                                                                  |
| Tests                                              | Partial                                       | `pnpm test` (4 contract tests); `cargo test` (3 tests including real temporary linked worktrees, working/staged/committed/untracked, rename, Unicode, binary/large limits, total diff, index preservation, manual branch/commit/unresolved bases, watcher event filtering). Bridge/UI automation, detached/inaccessible-base matrix, interrupt/concurrent mutation matrix remain gaps |
| macOS build                                        | Verified                                      | ARM64 `.app` at `src-tauri/target/release/bundle/macos/Diffscape.app`; build and native launch verified. DMG packaging was attempted earlier but Tauri's bundled Finder AppleScript timed out, so configured output is `.app` only                                                                                                                                                    |
| CI / publishing                                    | Not configured                                | No GitHub Actions or PR; implementation commits are local/worker-branch only per user instruction                                                                                                                                                                                                                                                                                     |

The app does not fetch, push, use a hosted service, or intentionally write to inspected repositories. Git state is a snapshot and may change externally between scans. Visual browser fixtures are development-only and do not ship as production data.

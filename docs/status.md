The app does not fetch, push, use a hosted service or intentionally write to inspected repositories. Git status is a snapshot that may change externally between scans. Long-running watcher stress, detached/inaccessible-base and adversarial concurrent-mutation matrices, external-editor app launch automation, native Tauri UI automation, VoiceOver QA, and DMG/signing remain gaps. E2E fixtures are development-only. Run `pnpm install --frozen-lockfile`, `pnpm dev`, `pnpm tauri:dev`, `pnpm test`, `pnpm exec playwright install chromium` (one-time browser setup), `pnpm test:e2e`, `cargo test --manifest-path src-tauri/Cargo.toml`, and `pnpm tauri:build`.
